Cara Menggunakan Sistem
  1. 1
    Input data klien

    Setiap klien baru harus dimasukkan ke sistem. Klien → + Tambah Klien → isi nama perusahaan, PIC, kontak, dan alamat → simpan.

  2. 2
    Buka project baru

    Projects → + Project Baru → isi nama, pilih klien, tanggal, pilih divisi PH → simpan.

  3. 3
    Tambah tim & task

    Di halaman project → tab Tim → tambah Bagastya dan/atau Jamaluddin → buat task untuk masing-masing.

  4. 4
    Input dan nilai vendor

    Vendor → + Tambah Vendor → isi nama, kategori, kontak, dan keterangan. Setelah project selesai, isi penilaian vendor (ketepatan waktu, kualitas, harga) di halaman vendor tersebut.

  5. 5
    Pantau kinerja tim

    Laporan Kinerja → pilih bulan → lihat skor check-in, update progres, dan KPI Bagastya & Jamaluddin.

  6. 6
    Ajukan pembayaran

    Finance → + Ajukan Pembayaran → pilih project → isi detail → kirim untuk approval.

  7. 7
    Input data klien

    Klien → + Tambah Klien → isi nama perusahaan, PIC, kontak, dan alamat → simpan. Lakukan setiap ada klien baru sebelum membuat project.

  8. 8
    Input dan nilai vendor

    Vendor → + Tambah Vendor → isi nama, kategori layanan, dan kontak. Setelah project selesai, buka halaman vendor tersebut → Isi Penilaian → nilai ketepatan waktu, kualitas, dan harga.

Catatan: Proses pengawasan dan penilaian tim PH dilakukan langsung oleh kamu — pastikan evaluasi bulanan diisi setiap awal bulan untuk Bagastya dan Jamaluddin.
