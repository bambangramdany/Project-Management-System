Kamu adalah bagian dari tim Production Event — mendukung jalannya project di lapangan dan memastikan semua kebutuhan teknis tersedia.
Menu yang Kamu Gunakan
📋
Tugas Saya

Check-in harian dan semua task yang ditugaskan ke kamu.

📁
Projects

Lihat project yang kamu ikuti — detail brief dan task.

🎯
Event Day

Rundown hari-H, konfirmasi kehadiran, laporan masalah.

🤝
Vendor

Input vendor yang digunakan di lapangan dan isi penilaian kinerja vendor setelah project selesai.

📊
Penilaian Saya

Isi self-assessment KPI bulanan kamu sendiri dan lihat skor serta akumulasi kinerja.

⭐
Nilai Tim

Beri penilaian KPI bulanan dan penilaian per project untuk anggota tim pasanganmu.

Cara Menggunakan Sistem
  1. 1
    Check-in harian

    Tugas Saya → Check-in setiap pagi → isi kondisi kehadiran.

  2. 2
    Kerjakan task produksi

    Klik task yang ditugaskan PM → kerjakan → Update Progres setiap hari.

  3. 3
    Hari-H event

    Event Day → konfirmasi kehadiran → ikuti rundown → laporkan masalah.

  4. 4
    Input vendor yang digunakan

    Vendor → + Tambah Vendor → isi nama, kategori (transportasi, catering, peralatan, dsb.), dan kontak → simpan.

  5. 5
    Nilai kinerja vendor

    Setelah project selesai, buka halaman vendor → Isi Penilaian → nilai ketepatan waktu, kualitas, dan harga berdasarkan pengalaman langsung di lapangan.

  6. 6
    Isi self-assessment bulanan

    Penilaian Tim → tab "Penilaian Saya" → pilih periode bulan ini → isi nilai untuk setiap kriteria KPI → kirim. Lakukan paling lambat tanggal 23 setiap bulannya (data HR diambil tanggal 24).

  7. 7
    Beri penilaian tim

    Penilaian Tim → tab "Nilai Tim" → KPI Tim → pilih Doddi Chaeril atau Noval Suherman (pasangan penilaianmu) → isi penilaian KPI bulanan → isi skor untuk setiap kriteria → simpan.

Catatan: Laporkan masalah teknis di lapangan melalui fitur Event Day agar tercatat di sistem.
